# Restoring this export

Every file in this archive (except this one) has had `.txt` appended to its
original filename -- e.g. `backend/main.py` was renamed to
`backend/main.py.txt`. This is *only* to get past Gmail's attachment
scanner, which blocks emails containing certain file types (including
`.js`) anywhere inside a zip, even nested. Nothing about the file contents
changed -- only the name.

To restore the original project layout, extract this zip and run **one**
of the commands below from inside the extracted folder. Both recursively
strip the trailing `.txt` from every file and leave directory structure
untouched.

## macOS / Linux / Git Bash (bash)

```bash
find . -type f -name "*.txt" ! -name "RESTORE.md" -exec sh -c 'mv "$1" "${1%.txt}"' _ {} \;
```

## Windows PowerShell

```powershell
Get-ChildItem -Recurse -File -Filter *.txt |
  ForEach-Object { Rename-Item $_.FullName -NewName ($_.Name -replace '\.txt$', '') }
```

After restoring, you should have the normal project layout (`backend/`,
`frontend/`, `tests/`, `README.md`, `.gitignore`, etc.) ready to push to a
fresh GitHub repository.

## What's included / excluded

This export contains only what `git ls-files --others --exclude-standard`
considered publishable in the original repo -- i.e. everything **except**
what the project's own `.gitignore` already excludes: Python virtualenvs,
`node_modules`, build output (`dist/`), local SQLite DB files, uploaded
images, downloaded model weights (`*.pt`), caches, and logs. Two
additional local build artifacts (`tsconfig.app.tsbuildinfo`,
`tsconfig.node.tsbuildinfo`) were excluded as well since they're
regenerated automatically and aren't meant to be version-controlled.

Once restored, follow the "Local development" section of `README.md.txt`
(soon to be `README.md`) to reinstall dependencies and run the project --
those aren't included here since they're regenerated by
`pip install`/`npm install`, not part of the source.
